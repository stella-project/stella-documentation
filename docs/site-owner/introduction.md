# Introduction

This is the introduction page for the site owner

### What is the STELLA APP?

The STELLA App is a multi-container application deployed at partner sites to:

+ serve experimental rankings and recommendations
+ collect user interaction feedback
+ forward feedback data to the STELLA Server

It is composed of multiple micro-services built using the STELLA micro-template and is typically deployed via Docker Compose.

The app acts as the execution and experimentation layer, while the STELLA Server acts as the data aggregation and persistence layer.
